## 5. XML i Markdown

Observa aquests dos fragments, que guarden exactament la mateixa informació sobre tasques quotidianes.

### Opció A (XML)

```xml
<tasques>
  <tasca estat="completada">
    <descripcio>Posar aigua a bullir</descripcio>
  </tasca>
  <tasca estat="pendent">
    <descripcio>Coure els fideus 3 minuts</descripcio>
  </tasca>
</tasques>
```

### Opció B (Markdown)

```markdown
- [x] Posar aigua a bullir
- [ ] Coure els fideus 3 minuts
```

**a)** Quina de les dues opcions és més ràpida d'escriure i més fàcil de llegir per a una persona quan obre el fitxer en un editor de text pla sense cap visor?

**b)** Si l'opció B és tan simple, per quina raó un sistema informàtic o una base de dades preferiria rebre o processar la informació en format XML (opció A) quan s'envien dades entre servidors?
