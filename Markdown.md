#### Text 1: Introducció a Java


**Java** és un dels llenguatges de programació més utilitzats en l'àmbit empresarial. És
un llenguatge *orientat a objectes* i destaca per la seva capacitat d'executar-se en
qualsevol sistema operatiu gràcies a la *Màquina Virtual de Java* (JVM). Tot
programa en Java necessita un **mètode principal** anomenat **`main`** per poder
executar-se.

``` java
// Programa bàsic en Java
public class HolaMon {
 public static void main(String[] args) {
 String nom = "Estudiant";
 System.out.println("Hola, " + nom + "! Benvingut/da a Java.");
 }
}
```
