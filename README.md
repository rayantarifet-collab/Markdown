# Introducción a Java en Markdown

Este proyecto contiene un único documento: [`Markdown.md`](./Markdown.md).

## Sobre el archivo

`Markdown.md` es un ejercicio de formato Markdown con una breve introducción a Java. Presenta algunas características del lenguaje y muestra un programa básico que imprime un saludo en la consola.

El ejemplo de código está escrito en Java e incluye el método `main`, punto de entrada habitual de un programa Java.

## Cómo verlo

Abre `Markdown.md` en GitHub o en un editor compatible con Markdown, como Visual Studio Code, para consultar el texto formateado y el bloque de código.
